# State diagrams

Lifecycles decide which links a client sees, so their diagrams show exactly what a person or agent can do with a board or capability in each state.

Generated from the XState machine or the JSON lifecycle definition, never drawn by hand ([ADR-0006](../../adr/0006-state-pattern-lifecycles.md), [ADR-0013](../../adr/0013-diagrams-as-code.md)). The board lifecycle arrives in INC-00c.
