# API

The same board and gadget resources serve the Armature UI, MCP clients, peer agents, and channels, so the API reference is the contract that lets Armature deliver anywhere.

- [TMF 630 conformance](tmf630-conformance.md): the query, patch, and identity rules every resource follows, and the two deliberate deviations (RFC 9457 errors, no version in paths).
- Errors: every error is an RFC 9457 problem whose help page is in [`docs/help/problems/`](../help/problems/) ([ADR-0019](../adr/0019-rfc9457-problem-details.md)).
- Try it: [`backend/http/board-resources.http`](../../backend/http/board-resources.http).
- OpenAPI is generated by springdoc at `/v3/api-docs` (the springdoc default path; the version in it is springdoc's, not Armature's) and browsable at `/swagger-ui.html`.
