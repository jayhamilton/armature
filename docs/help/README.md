# Help catalog

One help catalog feeds the in app help panel, the public user guide, and the assistant, so people and agents get the same answer.

Subdirectories `gadgets/`, `problems/`, `tasks/`, and `concepts/` arrive in INC-01, when the first problem types are published and the existing gadget help moves here ([ADR-0014](../adr/0014-docusaurus-user-guide.md)).
