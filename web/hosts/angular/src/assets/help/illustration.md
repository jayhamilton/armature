## Illustration

A decorative [unDraw](https://undraw.co) illustration — for empty-state
framing, section breaks, or general visual polish alongside your data
gadgets.

### Configuration

- **Title / Subtitle** — optional, shown in the gadget header.
- **Illustration** — pick from the curated set in
  `src/app/shared/illustrations/illustration-options.ts`. A thumbnail with a
  broken-image icon means the SVG hasn't been added to
  `src/assets/images/illustrations/` yet — see that folder's README.
- **Alt Text** — accessible description of the illustration; falls back to
  the gadget title if left blank.
- **Caption** — optional line of text shown beneath the illustration.
- **Size** — Small (120px), Medium (240px, default), or Large (400px) max width.

### See also

The Text gadget's markdown editor has its own "Insert illustration" toolbar
button, for placing an illustration inline within narrative content instead
of as its own gadget.
